# Snowflake Openflow Components

[Snowflake Openflow](https://www.snowflake.com/en/product/features/openflow/) Components for integrating with Snowflake using [Apache NiFi](https://nifi.apache.org).

## Requirements

- Java 21
- Maven 3.9

## Building

This project uses [Maven](https://maven.apache.org) to build distribution packages.

This project includes the [Maven Wrapper](https://maven.apache.org/wrapper/) to build with required Maven versions.

```
./mvnw install
```
